# Тамагочи-кликер

Учебный проект: консольная игра «Тамагочи» на Python, написана на ООП.
Питомец — кот Мурзик. За ним нужно следить: кормить, лечить, играть с ним
и укладывать отдыхать. Всё это стоит монет, а монеты зарабатываются работой.

## Правила

- У Мурзика четыре показателя от 0 до 100: голод, усталость, энергия, здоровье.
- Каждое действие (работа, покупка, кормление, игра, отдых, лечение)
  занимает час: голод и усталость растут, энергия тратится,
  а Мурзик может заболеть.
- Болезнь отнимает здоровье и сильнее утомляет, отдых при ней вдвое слабее.
  Лечит лекарство.
- Если голод или усталость на максимуме или энергия кончилась,
  здоровье тоже падает.
- Игра с Мурзиком поднимает здоровье, но только если он здоров.
- Еду и лекарства игра выбирает сама: покупается первый товар магазина,
  на который хватает монет, а кормят и лечат тем, что лежит в сумке
  первым. Каждое лечение тратит одну дозу лекарства.
- Когда здоровье падает ниже нуля, игра заканчивается.

## Как запустить

Нужен Python 3.12. Сама игра работает без сторонних библиотек.

```
python main.py
```

## Тесты и линтеры

```
py -3.12 -m venv .venv
.\.venv\Scripts\python -m pip install -r requirements.txt
.\.venv\Scripts\python -m pytest ./tests
.\.venv\Scripts\python -m ruff check ./game
.\.venv\Scripts\python -m flake8 ./game
```

На Linux/macOS вместо `.\.venv\Scripts\python` пишется `.venv/bin/python`.

## Структура

- `game/tamagochi.py` — питомец и его показатели.
- `game/clicker.py` — кликер, который приносит монеты.
- `game/game.py` — игра: кошелёк, сумки, покупки, конец игры.
- `game/models.py` — еда и лекарства.
- `game/exceptions.py` — ошибки игры.
- `main.py` — консольное меню, точка входа.
- `tests/` — тесты на pytest.
